Matnni yangi alifboga öğiriş

Eski lotin (oʻ, gʻ, sh, ch) yoki kirill yozuvidagi matnni yozing yoki qöying — natija darhol paydo böladi.

    Yangi özbek alifbosi

    2026-yil 21-oktabrdagi OʻRQ-1184-son Qonun bilan tasdiqlangan. Kuçga kiriş sanasi: 2027-yil 22-aprel.

    Klaviaturada qanday yoziladi

    • Windows / macOS: «Turkish Q» klaviatura sxemasini qöşing — Ö Ğ Ş Ç alohida tugmalarda.
    • macOS: o tugmasini bosib turing → ö; s → ş; c → ç; g → ğ.
    • Telefon: harfni bosib turing — variantlar çiqadi.

    Word uçun qöşimça

    Word ilovasida bitta tugma bilan butun hujjatni yangi alifboga öğiriş.

    1. Manifest faylni yuklab oling.
    2. Word → Qöyiş (Insert) → Qöşimçalar (Add-ins) → Upload My Add-in → faylni tanlang.
    3. Boş sahifa (Home) lentasida «Yangi alifbo» guruhi paydo böladi: Hujjatni öğiriş.

    Taşkilot uçun: Microsoft 365 Admin Center → Integrated apps → manifestni yuklang — qöşimça barça xodimlarda avtomatik paydo böladi.

    Muhim

    • Eski alifboda berilgan hujjatlar (pasport, guvohnoma, pul, qimmatli qoğozlar) kuçini saqlaydi.
    • Lavhalar va belgilar yaroqsiz holga kelguniça yoki belgilangan muddatgaça işlatilişi mumkin.
    • Imlo qoidalari Vazirlar Mahkamasi dasturi bilan aniqlaştiriladi — dastur yangilanib boriladi.
